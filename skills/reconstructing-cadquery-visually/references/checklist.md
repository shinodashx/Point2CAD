# 建模与验收检查表

## 输入和测量

- NPY：`allow_pickle=False`，实数 N×3；额外列明确指定，3×N 不自动转置。PLY：按 x/y/z 字段读取 ASCII／二进制，忽略并记录 faces／颜色／法线。文本：三元组数组或逐行空格／逗号 XYZ，不用 `eval`。
- 原始索引为从 0 开始的数据行／vertex 索引；保留原始行序和重复点，无效点默认拒绝。读取器的完整性测试可以检查坐标未改变，但不得把数值特征统计暴露给建模分析。
- 单位未知时保留原尺度并标未知；若暂按毫米输出，说明是假设。点云和模型处于同一坐标系；禁止 PCA 自动定轴或 ICP 对齐。相机取景不变更几何坐标。
- 原文件、渲染脚本、命令、截图及最终导出物保存哈希。NPY／PLY／文本都只根据绘出的点分析，不照搬其他输入的分区、尺寸或类别假设。图上坐标尺仅用于目视估计，不输出端点读数表或自动图像测量结果。
- 孔必须在多视图中有孔壁／边界证据，缺点不等于孔；窄弧不足以确定半径。平直区和折弯区分别观察厚度，旋转件分别观察端面、凹槽与台阶；阵列／镜像先观察复核再施加。
- 局部调参保持少量、可解释；记录图像证据和估计范围，不做坐标或像素拟合。复杂自由形状只有在截面视图有证据时才用少量控制点的 Sketch/Sweep/Loft，并声明近似；数据不足时索要更多视图／已知尺寸。

## 序列与圆角接合

- S 步骤写清“输入 body → 基准和草图 → 参数化操作 → 输出 body → 检查”。保留命名中间结果，不导入旧实体。输出是新建的可重放序列，不是唯一原始特征树；STEP 不保存 Python 特征历史。
- 检查工作平面法向、挤出方向、Revolve 轴、Sweep 截面方向、Loft 截面对应与扭转、Shell 开口／壁厚、阵列相位和变换顺序。
- 相接处先排除基准错位、壁厚错误及低精度截断造成的薄片／微台阶，再决定是否圆角。不能把部件运动间隙“抹平”。
- 受力凹根常在 Union 后、孔槽前做；倒角通常在根部圆角后做。按局部拓扑调整，不机械地把所有圆角放最后。
- 用 body、几何类型、坐标／方向／半径和邻面选边，验证数量与位置；避免不稳定边索引或全局无差别 `edges().fillet()`。
- 圆角失败检查半径、邻面、薄壁和特征次序，不能 `try/except: pass`。圆角加／减料后复查壁厚、干涉和切点；高光连续不等于几何相切。
- 轴承座、摩擦面、定位端面、导销孔保留必要平面与配合。刀具体不导出；delete body 是活动对象／装配清单排除，不冒充原生删除历史。

## 精度与最终实体

- 确认单位、用途及可观察目标。源点云数值精度未评估，不输出 RMS、P95、最大距离、阈值比例或逐点误差；图像相似不证明满足表面／制造公差。要求数值精度认证时说明本模式不足，只有用户同意后才切换模式，另记报告。
- 提交全量点绘制，并从正交、背面、斜视和局部显示切片复核；点被提交不等于每个点可见。报告逐视图／逐区域的轮廓、开口、连接与遮挡问题，不能只挑最像的一张图。
- 点云与模型采用相同坐标、相机、比例和裁切；优先并排不透明图，叠加仅辅助。只裁切显示、不造截面封盖；记录裁切规则，不将裁掉区域当不存在。不能由隐藏接触面的不可见推断模型正确或错误。
- 保存 STL 线性／角度离散参数；细化显示检查棱角是否来自网格离散，并用 CAD 的 BRep 截面复核真实结构。禁止点到 CAD 距离／误差色图作为视觉模式的间接数值输入。
- 融合会消除接触面：分别验证部件表面与最终融合体，不能只展示较小的那个；每个实际导出的变体都必须有效，否则修复或明确排除出交付。
- 静态多实体重建也要做部件两两相交体积检查。按单位/内核精度记录数值容差；零相交不证明存在运动间隙、完整隐藏结构或可制造装配，正体积干涉必须定位解释和处理。
- 干净进程重跑序列，STEP 重新导入检查有效性、实体数、关键位置和尺度。单件 STL 检查封闭、朝向、退化面、正体积；用截面／探针检查孔槽贯通与壁厚。
- 渲染工具不完成 CAD 有效性、STL 完整性及装配验收；须另用 CadQuery／内核检查新建几何，不读取源点云进行测量。
- 查看真实 CAD 导出物的整体／背面／截面／接合放大图；修改圆角时同机位前后对比。未渲染或未查看就明示限制，不用 AI 图片代替。
- 视觉偏差或建模缺陷按 [通用迭代流程](refinement.md) 修正；每轮复查全部视图及原有合格区域。交付核对最终文件哈希，避免沿用旧截图报告；实体有效性、装配检查和视觉检查不可互相替代。

## 装配和改型（仅在需要时）

- 保留固定／旋转／浮动件及各自轴线、行程、止挡和父子变换。不要融合运动件后整体旋转伪装机构。
- 检查释放、接触、极限姿态及角度采样；两两正体积干涉不能静默豁免紧固件。离散检查不是连续扫掠证明，动画不是摩擦／制动力学仿真。
- 忠实重建先保存基线；胎纹、制动机构等功能改型另建序列，按新设计目标验收，不宣称原点云证明了新增结构。
- 报告必须包含单位／变换、目标、误差定义、检查命令与结果、近似区域、输出文件；不把静态接触当夹紧力，也不保证载荷、抓地力或制造公差。
