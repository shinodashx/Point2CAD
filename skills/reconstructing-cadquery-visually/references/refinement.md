# 视觉驱动的通用重建与迭代

用于首次建模的特征选择，以及视觉偏差、接合异常或无效实体后的修正。保留原有基线→定位→反证→修改→复验闭环，只把源点云数值证据替换成视图证据；不使用类别模板、固定半径、固定分区或固定轮数。

## 1. 先检验特征假设

- 保存候选区域截图、图中位置、视角、显示裁切及尺度来源；比较时保持相同设置。只为显示隔离而筛点，不统计或拟合该区域；保留未裁切整体视图。
- 目视比较简单可解释候选：平面/圆柱、直线/圆弧、挤出/回转、等厚偏置/独立内外壁。由多视图及显示切片中的形态一致性判断，不从外圆推定其他面同轴。
- 增加未用于初次估计的视角与显示切片复核；记录短弧、重叠、稀疏和遮挡的不确定性。不能为了更像一张图增加无证据自由度。
- 估计值、采用名义值及最终图像差异分别记录。只能描述观察到的弦状外观，不能没有数值测量就断言剩余偏差属于噪声或源网格弦差。

| 需要区分的结构 | 视觉检查 | 操作选择 |
|---|---|---|
| 平面内壁与圆柱外壁 | 独立看内外壁侧视及多层显示切片，不能只看外轮廓 | 不强制Shell；可用Extrude/Cut构成内壁、Revolve构成外侧 |
| 圆柱折弯与回转环面 | 观察截面沿直线是否不变，或是否随轴旋转 | 固定圆弧截面Extrude/Sweep，或截面Revolve |
| 平直段接曲面 | 观察过渡、切向和伸入区域；新建草图用相切约束求解 | 在切点终止平板，再用相切Sketch/局部Fillet接合 |
| 端平面与径向端盖 | 换视角独立看端面朝向，不只看外圆角度范围 | 以有图像证据的construction plane裁切 |
| 镜像/阵列与近似相似零件 | 目视复核多个视角的中心、厚度和布局 | 有证据才Mirror/Pattern；否则分别建模 |

## 2. 每轮执行同一闭环

1. **保存基线。** 每轮独立目录保存可重放序列、参数/假设变化、证据、CAD 检查及几何哈希；记录源文件、坐标系、单位、相机、比例、显示裁切、渲染版本和离散设置。保持可观察目标不变，不改变机位来掩盖偏差。
2. **定位差异。** 查看全部基准视图，定位整体轮廓及局部接合的差异并追溯到特征及S步骤。区分结构、尺寸、边界、接触面遗漏和显示问题；不只优化最有利视角。
3. **提出可证伪修改。** 写清原假设、截图反证、候选 CAD 操作及预期改善的视角／区域。一次修改一个相关特征组，保留已有依据的尺寸；看不清时补视图，不虚构孔、圆角或隐藏结构。
4. **修改并检查实体。** 更正特征类型后再调少量尺寸；更新证据与计划，重跑完整序列。检查所有部件及拟交付融合体的有效性、实体数、正体积与局部壁厚，失败不得被视觉相似掩盖。
5. **同条件全视图复验。** 重新渲染真实导出物，对修正区域、原有合格区域及关键孔槽逐视图比较，补充反面和接合放大图。记录改善／退步／不确定及 CAD 检查；不计算点云残差，不生成残差色图。
6. **保留或拒绝候选。** 仅保留几何有效、符合证据且改善目标的候选；局部退步必须解释并满足关键约束，不能拿整体相似抵消关键特征失败。只回退自己的候选，不影响其他工作；输出逐轮截图及比较表。

## 3. 数值内核与观察误判

- 先修正坐标截断、非相切草图、薄片和错误接触，再考虑布尔容差。不得用固定大容差掩盖结构错误；容差必须结合单位、局部最小特征和目标精度选择，并记录前后体积、孔槽、干涉及有效性。未经验证的修复/融合不作为交付物。
- 圆角可能增料或减料，不能从图上边缘不齐直接推导增加圆角。源点云用多视图观察过渡，新建 CAD 用切点、截面和邻面检查相切；高光不证明几何相切。
- 透明叠加、投影重叠、漂浮点和未封盖显示裁切都不证明实体干涉／破面。用不透明图和图例消除显示误判，以 BRep 相交体积及 CAD 截面检查模型；不能用源点云距离绕过视觉模式边界。

## 4. 停止与交付条件

- **视觉目标满足：** 所有可观察整体／局部目标一致，实体／网格／装配检查通过，导出后重验且已查看实际渲染。明确标注“视觉近似，点云数值精度未评估”，不把它称为公差认证。
- **证据受限或停滞：** 补充视角、显示切片及替代结构仍不能区分参数，或改善一处却持续破坏其他区域。记录已尝试假设、逐轮图像差异、受限区域和缺失约束，保留最佳有效近似，具体索要该区域视图、尺度或加密点云。不能仅以“点少”跳过可修问题，不追求固定轮数；不暗中切换数值方法。
- 最终脚本独立于分析输入；源文件、序列及STEP/STL哈希与实物一致。旧截图及验证记录只作历史；保存渲染命令以复现证据，CAD 检查命令能复算实体质量。不得填写未经测量的逐点误差。
