# 点云到 CadQuery 序列重建 · 纯可视化 / Visual-only

把点云当测量证据，而不是待转换的几何实体。**NPY、PLY、粘贴 XYZ 必须执行同一流程：读取 → 分析 → 特征与尺寸证据 → CAD 操作计划 → 序列建模 → 误差闭环。**

## 硬性规则

- **点云分析仅看实际渲染。** 程序只负责安全解码、完整性校验、哈希、按原坐标绘点、显示取景／裁切／坐标尺；这些不是特征测量。禁止读取 XYZ 数值表、包围盒尺寸报告、PCA、直方图、数值截面、局部拟合、ICP、点到面残差或自动图像拟合／优化来建模与迭代。不能借用混合版／数值版的分析结论，即使坐标已在对话中也只原样保存交给渲染器。
- PLY 只读取顶点 XYZ，即使有 faces 也不使用其面造型。禁止 Poisson／alpha shape／三角片缝合／网格转实体／整体 NURBS 拟合代替重建。
- 从多视图轮廓、图上坐标尺／已知尺寸目视估计少量有意义的参数，记录估计范围，不冒充数值实测。证据反驳当前结构时先更换特征假设再调参；不逐点描摹。CAD 内部草图约束、相切求解、拓扑／体积／干涉计算仍保留，它们检查新建模型，不分析源点云。
- 最终 `sequence_cq.py` 只依赖 CadQuery、标准库和明确参数，不读取点云、旧 STL／STEP／BRep 或分析脚本。用 S01、S02…显式线性步骤构建；不把主体藏进整模型函数／循环。重复几何优先阵列、镜像。
- 重建与功能改型分开保存；不根据物体类别补造隐藏轴承、刹车等。稀疏点云不能保证唯一恢复原 CAD 历史或任意绝对精度。

## 执行流程

1. **验收输入。** 文件交给本技能读取器；粘贴坐标原样保存。遇到截断、缺行、省略号先找完整附件，找不到就要求补全。记录原文件哈希、点数、索引规则、单位及目标；不静默缩放、转置、删点或去重。只能查看读取元数据和渲染，不能调用混合版统计读取器。
2. **重新理解。** 以六向正交、多角度、背面及必要的显示切片／接合放大图识别主平面、轴、厚度、台阶、孔槽、凹槽、折弯和圆角。分别观察内外壁及端面，不从外形相似推定同轴、等厚或径向边界。显示切片只能筛点绘图，不计算截面参数。保存相机、比例、裁切规则及局部→世界变换，至少用两个非共线视角复核特征，不能丢掉稀疏小特征。
3. **建立证据。** 写 `feature_evidence.csv`：特征／部件、截图路径和哈希、图中区域、视角／显示设置、估计值与范围、采用值、尺度来源、置信度、假设。未测量的支持点数、拟合残差写 N/A，不能编造。区分观测、推断和未知；尺寸取整、对称和简化要回到多视图复核。无可读尺度时索要已知尺寸，或明确仅为相对比例近似。
4. **安排 CAD 操作。** 写 `feature_plan.md`：S 编号、body、依赖、construction plane、草图尺寸／约束、操作及方向、预期实体数、证据。按下表选择，不为凑清单强行用所有操作。
5. **执行并修正。** 编写独立序列，先主形体后局部特征；复杂 Boolean／圆角后检查每个实体有效、非空、正体积及数量。圆角接合与验收细则见 [references/checklist.md](references/checklist.md)，建模前阅读。不能跳过失败特征继续报成功。
6. **闭环验证与迭代。** 按相同相机、正交比例和裁切条件并排查看点云与真实 CAD 导出物，检查整体、背面、截面及接合放大图；不能各自自动居中／缩放掩盖偏差。保留部件表面与融合体检查、孔槽及 CAD 干涉检查。视觉偏差或无效实体按 [references/refinement.md](references/refinement.md) 定位→反证假设→修改操作→全视图复验；不调用点到面距离来指导修改。保留逐轮序列、截图、差异说明及文件哈希，不仅在报告里承认问题。
7. **交付。** 原输入来源与读取报告、证据表、计划、`sequence_cq.py`、STEP、需要的STL、逐轮比较、可复现 CAD 验证与已查看的渲染。核对报告与最终文件哈希一致；说明单位、目标、近似及未观测区域。点云数值精度标为“未评估”，不编造逐点误差或宣称满足绝对公差；本模式只能确认视觉一致性和 CAD 质量。满足可观察目标或有记录的证据不足／停滞后才结束，不承诺任意输入都能唯一恢复。只有要求运动时才增加运动脚本及状态检查。

| 几何证据 | CAD 操作 |
|---|---|
| 恒定截面、板、孔槽、凸台 | Sketch + Extrude／Cut／Hole／cskHole |
| 同轴台阶、锥面、回转槽 | 截面 Sketch + Revolve |
| 沿路径的恒定截面／连续变截面 | 约束路径 + Sweep／少量有证据截面 + Loft |
| 等厚开口薄壁 | Shell，检查开口面及偏置方向 |
| 连接过渡、去锐边 | 局部 Fillet／Chamfer |
| 重复、对称、组合、定位 | Circular pattern／Mirror／Boolean／Construction plane／Transform |
| 删除／替换 | 从活动 body／装配清单排除；工具体不导出 |

## 配套工具

`$SKILL_DIR` 为本技能目录。缺依赖时使用隔离环境；读取／渲染需 `numpy plyfile vtk`，建模与 CAD 检查需 `cadquery`。测试过 Python 3.11／CadQuery 2.8。输出目录须新建或为空，原输入不可覆盖。

```bash
# 三种格式使用相同读取／渲染入口；按实际输入选择一行
python "$SKILL_DIR/scripts/inspect_cloud.py" input.npy --out views
python "$SKILL_DIR/scripts/inspect_cloud.py" input.ply --out views
python "$SKILL_DIR/scripts/inspect_cloud.py" input_points.txt --out views
# N×6 等数据必须显式选择列；单位只有证据确认后才标 confirmed
# 可附加：--xyz-columns 0 1 2 --unit mm --unit-status confirmed

# 只读本轮新建 CAD 的导出 STL 进行显示，不将它导入建模序列
python "$SKILL_DIR/scripts/inspect_cloud.py" input.npy \
  --cad-stl result/component_surfaces.stl --out comparison
# 目视选定的放大范围可加 --focus X Y Z --view-span H；同轮比较须相同设置
python "$SKILL_DIR/scripts/test_workflow.py"
```

读取器绘制全量点，不输出数值特征报告；七张图生成后必须实际查看。缩放仍不足以辨识时补充旋转／显示切片并保存命令，不隐式切换数值分析。渲染不可用时先修复环境，仍失败则说明阻塞；不能凭已有 XYZ 数值继续称纯视觉重建。按检查表补全 CAD 验收，不把脚本退出码或图片相似当精度保证。
