# 数值驱动的通用重建与迭代

用于首次建模的特征选择，以及超差、系统性残差、接合异常或无效实体后的修正。依据输入证据选择操作，不使用零件类别模板、固定半径、固定分区或固定轮数。

## 1. 先检验特征假设

- 保存候选区域的原始索引、分区条件、点数与空间覆盖；比较候选时用相同区域。测量时区分面内点、端面、过渡和其他零件，局部剔除必须说明归属；全量验证不删点。
- 数值比较简单可解释的候选：平面/圆柱，直线/圆弧，挤出/回转，等厚偏置/独立内外壁；由残差分布和跨截面一致性决定，不因一个外表面是圆形就强制其他面同轴。
- 点数足够时留出空间分离的截面或区域复核；记录短弧、近平行面、病态拟合或遮挡造成的不确定性。用更多自由度降低训练残差，不代表结构更正确。
- 分别报告拟合参数残差、采用名义尺寸后的残差和最终CAD距离。量化取整影响；只有残差模式、截面证据及离散收敛支持时，才把偏差解释为噪声或源网格弦差。

| 需要区分的结构 | 数值检查 | 操作选择 |
|---|---|---|
| 平面内壁与圆柱外壁 | 独立检验内外壁的法向、径向残差和沿轴一致性 | 不强制Shell；可用Extrude/Cut构成内壁、Revolve构成外侧 |
| 圆柱折弯与回转环面 | 比较固定截面沿直线是否不变，或截面是否随轴旋转 | 固定圆弧截面Extrude/Sweep，或截面Revolve |
| 平直段接曲面 | 解切点、半径和切线连续性；检查平板是否伸进折弯区域 | 在切点终止平板，再用相切Sketch/局部Fillet接合 |
| 端平面与径向端盖 | 独立测量端面法向，不只观察外圆的角度范围 | 以实测construction plane裁切，而非猜测旋转角 |
| 镜像/阵列与近似相似零件 | 变换后比较平面层、中心、厚度和分区残差 | 有证据才Mirror/Pattern；否则分别建模 |

## 2. 每轮执行同一闭环

1. **保存基线。** 为本轮建独立目录，保存可重放序列、参数/假设变化、证据、验证结果及几何哈希；记录输入/索引哈希、坐标系、单位、阈值、表面类型与离散设置。未知制造公差时明确标为诊断阈值，不跨轮放宽它以制造达标。
2. **定位误差。** 同时查看最大误差点、全部超差点和空间聚集区域，追溯到具体特征及S步骤。区分结构、尺寸、裁切边界、接触面遗漏和数值离散问题；不能只优化全局RMS或某一个最差点。
3. **提出可证伪修改。** 写清原假设、反证、候选CAD操作及预期改善区域。一次修改一个相互关联的特征组；保留已验证尺寸。证据不足以区分候选时，不虚构孔、圆角或隐藏结构。
4. **修改并检查实体。** 更正特征类型后再调少量尺寸；更新证据与操作计划，重跑完整序列。检查所有部件及所有拟交付融合体的有效性、实体数、正体积与局部壁厚，失败不得被较低距离分数掩盖。
5. **同条件全量复验。** 对全部输入点、修正区域、原有合格区域及关键孔槽分别比较；允许区域重叠但要说明。记录N、均值、RMS、中位数、P95、最大、超差点数/比例、最差原索引及实体检查。比较STEP面与细网格以辨别真实误差和离散误差。
6. **保留或拒绝候选。** 仅保留几何有效、符合证据且改善目标的候选；局部退步必须解释并满足关键约束，不能拿全局改善抵消关键特征失败。只回退本次重建自己的候选，不影响用户或其他工作的修改。重新渲染实际导出物，核对数值定位的区域；输出逐轮比较表。

## 3. 数值内核与观察误判

- 先修正坐标截断、非相切草图、薄片和错误接触，再考虑布尔容差。不得用固定大容差掩盖结构错误；容差必须结合单位、局部最小特征和目标精度选择，并记录前后体积、孔槽、干涉及有效性。未经验证的修复/融合不作为交付物。
- 圆角可能增料或减料，不能由“边缘误差较大”直接推导“增加圆角”。用实际切点、截面、相邻面和数值残差验证；失败假设不写成最终建模规则。
- 不看点云或残差分布图。点到最近面距离不能确定零件归属；用原索引分区、坐标覆盖、BRep相交体积和数值截面交叉验证。纯 CAD 渲染只检查导出物缺陷，显示裁切不证明实体破面。

## 4. 停止与交付条件

- **达标：** 全局、局部和关键尺寸目标满足，实体/网格/装配检查通过，导出后重验且已查看实际渲染。整体RMS较小或大多数点达标不是全部细节准确。
- **证据受限或停滞：** 有证据的替代结构及数值误差检查后，剩余参数仍不可辨识，或候选仅降低局部训练残差却恶化其他区域。记录已尝试假设、逐轮指标、剩余原索引与缺失约束，保留最佳有效近似，具体要求补充该区域截面、尺寸或加密点云。不能仅以“点少”跳过尚可定位和修复的问题，也不为达到任意轮数追噪声。
- 最终脚本独立于分析输入；报告记录的源文件、序列及STEP/STL哈希必须分别与实际文件一致。重建后旧验证记录只作历史，不得继续称为当前结果；测量脚本须能重算证据，验证命令须能复算全部误差。
